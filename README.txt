Practical_02_Multithreading_Sleep_Yield

Core Java:
  javac FileName.java

Servlet programs use javax.servlet and are intended for Apache Tomcat 9.
JSP/Servlet programs need a Java web application project and Tomcat.
JDBC programs use MySQL and require MySQL Connector/J. Update YOUR_PASSWORD,
database name, and credentials to match your setup.

Do not upload passwords, API keys, .env files, or node_modules to GitHub.
